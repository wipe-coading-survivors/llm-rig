# Stage 24 CUDA dnf-репо Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** CUDA toolkit 13.2.2 (.run redist) → 13.3.x из официального dnf-репо NVIDIA (fedora44): `nvidia-cuda-devel`/`nvidia-cuda-libs` собираются через `dnf` (имена серии + опция точных NEVRA), `nvidia-redist-cuda` и `.run`-канал toolkit удаляются, layout `/opt/cuda` → `/usr/local/cuda`.

**Architecture:** Makefile-переменные `CUDA_REPO_BASE`/`CUDA_PKG_SERIES` (из `NVIDIA_CUDA_VER`)/`CUDA_DEVEL_SET`/`CUDA_RUNTIME_SET` (дефолт — имена серии, dnf решает самый свежий release; override в `local.mk` — точные NEVRA) передаются в containerfiles build-аргами; RUN-стадии `dnf install` из доставленного `curl`'ом `cuda-fedora44.repo` (weakdeps off) + аудит-файл `/usr/local/cuda-installed.txt`. `nvidia-cuda-libs` теряет зависимость от devel (dnf-установка runtime-набора, не tar-copy из devel-образа).

**Tech Stack:** GNU Make, Containerfile (podman/buildah `bud`), dnf5, POSIX-тест-скрипты (`scripts/test-*.sh`), git.

**Spec:** `docs/superpowers/specs/2026-09-01-cuda-repo-design.md` (ревью пройдено, 01.09.2026). Факты: `docs/superpowers/reports/2026-09-01-cuda-repo-precheck.md` (§1–§9).

## Global Constraints

- **no-inline-comments:** в Containerfile нет завершающих комментариев после инструкции — только отдельной строкой.
- **no-cre-hardcode:** инструмент — `CRE` (Makefile); тестовые скрипты не хардкодят podman/podman-remote.
- **english-commits:** сообщения коммитов — на английском.
- **dnf5:** имена пакетов/NEVRA **без суффикса `.rpm`** (суффикс = путь к локальному файлу, specced F2).
- **weakdeps off:** `--setopt=install_weak_deps=False` (спека F3).
- **Layout:** `/usr/local/cuda-<ver>` и альтернатива `/usr/local/cuda` — поставлены пакетами (F4): **нет** `ln -s /opt/cuda`, **нет** `20_local.conf`, **нет** `/opt/cuda` в новых containerfiles.
- **Makefile-формат:** continuation-строки — TAB + 2 пробела; команда — с одного TAB (пин 21a в graph-тесте).
- **no-sensitive:** значения local.mk не в tracked-файлах (в `local.mk.example` — только механизм, без значений).
- **Зелёный сьют** после Task 2: все `scripts/test-*.sh` (13 шт.) — `pass, fail=0`.
- **Live-окно — вне плана** (отдельный фаза после выполнения плана, по спеке §Live Window: nvidia-base первым, снимок/restore, NCCL/llama, cleanup `:13.2`).
- Машина: 2×Xeon 2080v4, 256GB RAM — сборки быстрые (контекст для live-окна; dry-run-задачи не строят).
