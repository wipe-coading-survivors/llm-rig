# Мемо: `test-no-sensitive` — полный скоуп, включая `docs/` (убрано исключение `:!docs`)

- Дата: 01.09.2026
- Статус: завершено

## Контекст

Этап 19 (выделение llm-rig) создал `scripts/test-no-sensitive.sh` со
скоупом «все tracked-файлы, кроме docs/» (`git ls-files -z ':!docs'`).
Обоснование на тот момент (спека §8, решение 31.08): в архив-репо
`docs/` = процесс-архив, несущий исторические значения по природе;
`docs/` в новое репо не переносится.

С Этапа 24 (01.09.2026) llm-rig аккумулирует собственные
процесс-документы (`docs/superpowers/{specs,plans,reports,memos}`) —
они попадают в `main` при finish этапа. При исключении `:!docs` новая
документация осталась бы вне проверки, хотя смысл теста —
чувствительно-чистое дерево целиком, включая документацию.

## Решение

Убрать исключение `:!docs`: скоуп = все tracked-файлы. Обновлены
header-комментарий скрипта и комментарий `tracked_grep`.

Затронуто: `scripts/test-no-sensitive.sh` (pathspec `ls-files`,
комментарии).

## Верификация (после работы)

- `sh scripts/test-no-sensitive.sh` в worktree `stage24-cuda-repo`
  (в скоупе `docs/`: спека пре-чека + `TODO.md`): `pass=2 fail=0` —
  текущая документация чиста (local.mk в worktree отсутствует —
  проверка значений пропускается, generic-часть проверена).
- Полный набор `scripts/test-*.sh` (13 скриптов): все проходят.
