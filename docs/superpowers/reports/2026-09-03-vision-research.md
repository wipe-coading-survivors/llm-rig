# Отчёт: подключение vision для сессии (изыскания + решение)

- Дата: 03.09.2026
- Статус: завершён — vision работает через Cloudflare Workers AI
  (`scripts/vision-ask.sh`, мемо `2026-09-03-vision-ask`)
- Инициация: вопрос пользователя — «можно ли показать агенту
  картинки/скриншоты и чтобы он их понимал».

## 1. Задача и исходное состояние

- Сессия opencode работает на живом llama-cpp-сервере (модель `default`,
  baseURL `127.0.0.1:8080`). Загруженная модель —
  `qwen3.8-27b-ud-q8_k_xl.gguf`; `/v1/models`: `input_modalities:
  ["text"]`, `output_modalities: ["text"]` — **vision отсутствует**.
  В `/var/local/llm/gguf-models` (NFS) ни одной VL-модели и ни одного
  mmproj.
- Вывод: агент (текстовая модель) картинку «увидеть» не может даже при
  вложении файла — нужен внешний (или локальный VL) распознаватель,
  возвращающий текст.

## 2. Разобранные варианты

### 2.1. Локальная VL-модель на этом сервере (llama.cpp + mmproj)

- Vision в llama.cpp = мультимодельная GGUF + `--mmproj` (ViT-проектор).
- Ограничение: сервер **одно-модельный** (VRAM 5×RTX 3060 = 60GB;
  текущая конфигурация — 58.3/60GB: модель 31.4GB + ctx 430k×2 слота +
  cache-ram 128GB). Т.е. не «добавить», а **сменить** модель (или
  ужать ctx основного и поднять второй инстанс впритык — рискованно).
- Смена модели = смена модели самой сессии + потеря конфигурации
  430k/128GB (восстанавливается обратным рестартом).
- Оценка: технически возможно (кандидаты: Qwen2.5-VL-32B-Q8 ≈ 36GB с
  ViT+mmproj, ctx → 150–250k), но дорого для текущего сценария
  («изредка показать скриншот»). **Не выбран**; держать в уме как
  вариант без внешних сервисов (приватность).

### 2.2. Google (Gemini)

- «Кнопка ИИ» в Google-поиске / Lens — потребительский Gemini.
  Автоматизированный доступ к consumer-поиску — нарушение ToS +
  anti-bot/CAPTCHA с datacenter-IP → **отклонено** (решение пользователя
  о рисках не меняет практической ненадёжности пути).
- Gemini API: **регион не поддерживается** (AI Studio недоступен из РФ —
  факт, страница региональных ограничений; ключ получить нельзя).
  `generativelanguage.googleapis.com` с хоста достижим, но без ключа
  бесполезен.

### 2.4. Выбранное: Cloudflare Workers AI

Обоснование (по фактам §2.2–2.3):

- достижим с хоста; Cloudflare не гео-блочит разработчиков (работает из
  РФ) — в отличие от Gemini API;
- free plan **без карты**, лимит 10 000 neural-кредитов/день — для
  изредка показываемых скриншотов с большим запасом;
- каталог (docs, 12.08.2026) содержит актуальные vision-модели:
  `qwen3.8-27b` (Vision+Reasoning+FC), `gemma-4-26b-a4b-it`,
  `glm-5.3-flash`, `kimi-k2.6`, `moondream3.1-9B-A2B` (быстрый, 2B
  active), `llama-3.2-11b-vision-instruct`;
- простой REST-интерфейс (OpenAI-совместимый chat-формат с data-URL
  картинки), не нужен MCP (MCP-тулзы раздувают контекст — предупреждение
  в доках opencode).
- Цена: **содержимое картинок уходит на Cloudflare** (инференс на
  edge'е). Для чувствительных данных — не использовать (§2.1 как
  приватный вариант).

## 3. Настройка и факты отладки

- Аккаунт: free, токен-шаблон **Workers AI: Read** (account-level),
  TTL до 01.04.2028, **client IP filtering** — в белом списке оба
  egress-IP сервера (`95.165.65.7` — верифицирован `api.ipify.org`,
  `77.51.218.27`).
- Ключи: `/etc/llama/cloudflare-ai.env` (600) — `CF_ACCOUNT_ID`
  (32 hex, из URL дашборда `dash.cloudflare.com/<id>/`), `CF_API_TOKEN`.
- Отладочные факты (все — живые ответы API):
  - `GET /client/v4/user/tokens/verify` — токен активен (`status:
    active`);
  - `GET /client/v4/accounts` — `success: true`, **пустой список**
    (у токена нет права листинга аккаунтов — не ошибка);
  - `GET /client/v4/accounts/{id}` — `9109 Unauthorized to access
    requested resource` (у токена нет `Account: Read` — **не**
    индикатор несовпадения аккаунта; проверено по сводке токена:
    «Dsrhdev@gmail.com's Account - Workers AI:Read»);
  - `GET .../ai/models` — `10001 Unable to authenticate request`
    (факт: с этим токеном каталог по API не читается; список моделей —
    по докам);
  - `@cf/qwen/qwen2.5-vl-7b-instruct` (кандидат из предположения) —
    `7000 No route for that URI` = slug отсутствует в каталоге
    (не ошибка аутентификации — роутинг проверяется отдельно).
- Итоговая модель по умолчанию: `@cf/qwen/qwen3.8-27b` (работает без
  «agree»; `llama-3.2-11b-vision-instruct` требует разового промпта
  `agree` по лицензии Meta — не использовалась).

## 5. Ограничения и риски

- **Приватность**: картинка уходит на Cloudflare (data-URL в теле
  запроса). Политика использования — решение пользователя; для
  чувствительных данных — локальный VL-вариант (§2.1).
- Free-tier лимит: 10 000 кредитов/день; крупная модель (27B) дороже
  мелкой в кредитах за токен — при массовом использовании переключиться
  на `@cf/moondream/moondream3.1-9B-A2B` (`VISION_MODEL`).
- Каталог Workers AI меняется: slug'и моделей устаревают (факт §3:
  `qwen2.5-vl-7b` исчез). Диагностика «нет модели» — `7000 No route`;
  список актуальных — по докам (API-каталог с этим токеном не читается).
- Токен с IP-фильтром: при смене egress-IP сервера запросы упрутся в
  `10001/9109` — добавить IP в фильтр токена.
